# BIOSTAT721Project2

## Project Description

This project explores daily air quality measurements collected from the EPA monitoring station at RDU airport. The analysis focuses on carbon monoxide (CO), fine particulate matter (PM2.5), and ozone (O3) concentrations from 2018 through April 2020. The goal is to clean the raw data, summarize pollutant concentrations, and explore monthly and seasonal patterns using tables and visualizations.

## Data Source

The data were obtained from the U.S. Environmental Protection Agency (EPA) and contain daily air quality measurements from the monitoring station at RDU airport. The datasets cover 2018, 2019, and January through April 2020.

## File Structure

- `AdamClineBIOSTAT721Project2.Rmd`: Main R Markdown file containing the data cleaning function, analysis, tables, and plots.
- `AdamClineBIOSTAT721Project2.docx`: Knitted Word document containing the final report.
- `data-7/data/`: Folder containing the original CSV files:
  - `AQ_2018.csv`
  - `AQ_2019.csv`
  - `AQ_2020.csv`
- `README.md`: Project description and instructions for reproducing the analysis.

## How to Reproduce

1. Download the repository
2. Open the RStudio Project
3. Make sure the original CSV files are located in `data-7/data/`.
4. Install the required R packages: tidyverse, gt, lubridate
5. Open `AdamClineBIOSTAT721Project2.Rmd` in RStudio.
6. Knit the R Markdown file to a Word document using the Knit button
